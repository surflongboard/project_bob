# Assumptions Register — Inventory Analysis

A new, third workstream (see top-level `CLAUDE.md`), built from a single
warehouse available-stock snapshot: `Available_stock_260825.xlsx`.

**This workstream deliberately reuses definitions from the SS26 Portfolio
Tiering workstream** rather than re-deriving them — cited by ID below and
in `scripts/analyze_inventory.py`. Read `data/ss26_portfolio_tiering/
ASSUMPTIONS_REGISTER.md` for the full reasoning behind each cited entry;
this file only records what's genuinely new here.

**Source file:** not duplicated. This workstream reads the copy already
checked in at `data/ss26_portfolio_tiering/inputs/stock/
Available_stock_260825.xlsx` directly (see REG-INV-001) — the file
uploaded to start this workstream is byte-identical (confirmed via md5).

**Reusable pipeline script:** `scripts/analyze_inventory.py` — reads the
source file, matches to franchise via `ss26_lib.franchise_key()`, joins
tier from the SS26 tiering workbook, and writes a dated output workbook
`Project_Bob_Inventory_Analysis_<DDMMYYYY>.xlsx` (never overwrites a
previous dated cut — same convention as `build_distribution_workbook.py`).
Re-run it any time the source snapshot or the tiering workbook it joins
against is updated.

**Reference style:** cite an entry by ID (e.g. "per REG-INV-004") in any
code, prompt, or report that depends on it.

| REG-INV-013 | Portfolio Analysis | Heuristic FW27 rename-candidate finder (Sheet 5) | **Provisional** (methodology), NOT a resolution of REG-INV-012 | Automates "which of REG-INV-012's 54 SS27-Active orphans might just be renamed, not really gone?" into a ranked candidate list — narrows the manual-review set, doesn't resolve it. Method: for each orphan, search FW27 styles of the same gender + `Business Area` for a shared **distinctive** word. "Distinctive" is decided positionally, not by raw frequency: a product-family name (e.g. "Rosson," "Korp," "Zircon") almost always *leads* the style name (or follows a brand prefix like "Haglöfs"/"L.I.M"), while a generic descriptor/garment noun ("Jacket," "GTX," "Proof," "Mid," "Hood") rarely does, regardless of how often it appears overall — raw frequency alone can't separate them (e.g. "Rosson" and "Mid" each occur 15-50 times across FW27's 392 styles, but only "Rosson" is a family name). Confidence: **HIGH** = shared distinctive word AND matching last word/garment noun (e.g. both end in "Hood"); **MEDIUM** = 2+ shared distinctive words, garment noun differs; **LOW** = exactly one shared distinctive word, garment noun differs. Up to 3 same-tier candidates are shown per orphan (not collapsed to one arbitrary pick) so the reviewer sees real ambiguity where it exists. **Result:** 15 of the 54 orphans (28%) got a candidate; the rest correctly returned none rather than a forced guess. Two HIGH-confidence examples worth a quick real check: "Rosson Softshell Hood" → "Rosson Down Hood" / "Rosson Mid Hood" (both Men and Women); "ROC Lite Slim Pant" → "ROC Sight Softshell Pant". **Explicitly not resolved by this entry:** whether any candidate is the *actual* successor — that's still a merch call, per REG-INV-012's Open status, which this heuristic narrows but does not close. Not validated against a known-correct answer set (no ground truth available in this repo) — treat hit rate and precision as unverified, not benchmarked. |

| REG-INV-014 | Portfolio Analysis | Inventory value estimate (Retail/Wholesale/Cost) — Sheets 2, 3, 6 | **Provisional** (methodology validated, figures not audited) | Answers a standing gap this workstream flagged from the start (REG-019/REG-INV-006: stock is units-only, no SEK value) — but only for the subset of stock matched to the FW27 plan. Retail Value = units × the FW27 plan's own `Target RRP` for that franchise; Wholesale Value = units × `WP`. **`LANDED COST SEK` itself is `#ERROR!` on every FW27 row (REG-INV-011)** — Est. Cost Value instead uses Landed Cost **reconstructed** as `WP × (1 − GM0%)`, which is algebraically what `GM0%` means by definition. **Validated, not assumed:** on the handful of SS27 rows where the real (non-broken) `LANDED COST SEK`, `WP`, and `GM0%` are all present together, the reconstructed value matches the real one exactly (to floating-point noise) — confirms the formula, not the FW27 figures themselves against an independent source. `GM0%` is numeric on 387 of 392 FW27 rows (5 are `#DIV/0!`); all 283 stocked, FW27-matched franchises happen to fall in the reconstructable 387. **Result:** of 527,963 total stock units, 400,773 (76%) are valued — 775.2M SEK at Target RRP, 370.7M SEK at WP, 145.8M SEK estimated landed cost (~60.7% implied margin on a WP basis). The remaining 127,190 units (24%, Sheet 4 "Not on FW27 Plan") have **no price source anywhere in this data** — shown as units-only, explicitly not zero. Sheet 6 breaks the valued total down by Priority Tier and by `NEW MAPPING: Activity` (column AN) — Long Runway (FW28+) alone accounts for 630.7M of the 775.2M retail value, so most of the valued inventory isn't urgent by REG-INV-010's own tiering; the FW27-exiting slice is a much smaller 56.5M at RRP / 12.0M at estimated cost. **Caveats that keep this Provisional, not Confirmed:** (1) `Target RRP` is a *planned* price — no discounting, no per-market currency variation, no realized-sales check; read Retail Value as a ceiling, not expected recovery. (2) One planned RRP/WP/cost per franchise is applied uniformly across every size and colorway currently in stock — real unit economics vary within a franchise and aren't captured. (3) Cost is reconstructed from the plan's own margin assumption, not cross-checked against Finance's actual landed-cost system — treat as internally consistent, not independently audited. |

## Glossary

| Term | Maps to |
|---|---|
| "Aged stock" | `Season Article` = `F25` or older per REG-INV-008 — **not** the same thing as REG-019's "clear via sale" tiers (Thin/Immaterial, Exited); the two overlap partially (REG-INV-009) but are independent signals. |
| "Incoming / Future stock" | `Season Article` = `F26` or `S27` per REG-INV-008 — pre-season stock, not a risk signal by itself. |
| "Sell-down priority" | A franchise ranked in Sheet 2 of `Project_Bob_Sell_Down_Priority_<date>.xlsx` per REG-INV-010 — has real stock AND a known, near-term planned exit from the FW27 assortment.
