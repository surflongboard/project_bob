# Assumptions Register — Inventory Analysis

A new, third workstream (see top-level `CLAUDE.md`), built from a single
warehouse available-stock snapshot: `Available_stock_260825.xlsx`.

**This workstream deliberately reuses definitions from the SS26 Portfolio
Tiering workstream** rather than re-deriving them — cited by ID below and
in `scripts/analyze_inventory.py`. Read `data/ss26_portfolio_tiering/
ASSUMPTIONS_REGISTER.md` for the full reasoning behind each cited entry;
this file only records what's genuinely new here.

**Source file:** not duplicated. This workstream reads the copy already
checked in at `data/ss26_portfolio_tiering/inputs/stock/
Available_stock_260825.xlsx` directly (see REG-INV-001) — the file
uploaded to start this workstream is byte-identical (confirmed via md5).

**Reusable pipeline script:** `scripts/analyze_inventory.py` — reads the
source file, matches to franchise via `ss26_lib.franchise_key()`, joins
tier from the SS26 tiering workbook, and writes a dated output workbook
`Project_Bob_Inventory_Analysis_<DDMMYYYY>.xlsx` (never overwrites a
previous dated cut — same convention as `build_distribution_workbook.py`).
Re-run it any time the source snapshot or the tiering workbook it joins
against is updated.

**Reference style:** cite an entry by ID (e.g. "per REG-INV-004") in any
code, prompt, or report that depends on it.

| REG-INV-013 | Portfolio Analysis | Heuristic FW27 rename-candidate finder (Sheet 5) | **Provisional** (methodology), NOT a resolution of REG-INV-012 | Automates "which of REG-INV-012's 54 SS27-Active orphans might just be renamed, not really gone?" into a ranked candidate list — narrows the manual-review set, doesn't resolve it. Method: for each orphan, search FW27 styles of the same gender + `Business Area` for a shared **distinctive** word. "Distinctive" is decided positionally, not by raw frequency: a product-family name (e.g. "Rosson," "Korp," "Zircon") almost always *leads* the style name (or follows a brand prefix like "Haglöfs"/"L.I.M"), while a generic descriptor/garment noun ("Jacket," "GTX," "Proof," "Mid," "Hood") rarely does, regardless of how often it appears overall — raw frequency alone can't separate them (e.g. "Rosson" and "Mid" each occur 15-50 times across FW27's 392 styles, but only "Rosson" is a family name). Confidence: **HIGH** = shared distinctive word AND matching last word/garment noun (e.g. both end in "Hood"); **MEDIUM** = 2+ shared distinctive words, garment noun differs; **LOW** = exactly one shared distinctive word, garment noun differs. Up to 3 same-tier candidates are shown per orphan (not collapsed to one arbitrary pick) so the reviewer sees real ambiguity where it exists. **Result:** 15 of the 54 orphans (28%) got a candidate; the rest correctly returned none rather than a forced guess. Two HIGH-confidence examples worth a quick real check: "Rosson Softshell Hood" → "Rosson Down Hood" / "Rosson Mid Hood" (both Men and Women); "ROC Lite Slim Pant" → "ROC Sight Softshell Pant". **Explicitly not resolved by this entry:** whether any candidate is the *actual* successor — that's still a merch call, per REG-INV-012's Open status, which this heuristic narrows but does not close. |---|---|
| "Aged stock" | `Season Article` = `F25` or older per REG-INV-008 — **not** the same thing as REG-019's "clear via sale" tiers (Thin/Immaterial, Exited); the two overlap partially (REG-INV-009) but are independent signals. |
| "Incoming / Future stock" | `Season Article` = `F26` or `S27` per REG-INV-008 — pre-season stock, not a risk signal by itself. |
| "Sell-down priority" | A franchise ranked in Sheet 2 of `Project_Bob_Sell_Down_Priority_<date>.xlsx` per REG-INV-010 — has real stock AND a known, near-term planned exit from the FW27 assortment. Distinct from "Aged stock" (REG-INV-008): one is about how old the stock already is, the other is about how soon the collection retires it. |
